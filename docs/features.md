# Features

The examples are the fastest way to see what `phasor` can do, but they are easier to navigate once the shared capabilities have names. This page groups those capabilities into the features that show up across the docs, then links each one back to the examples that exercise it directly.

The tags on example cards and guide pages point here so the feature language stays consistent. The page itself is not a glossary. It is meant to show what each capability is for, how it tends to look in code, and where to go next when you want a larger working example.
